## Not ported

- **design (gentle-design)**: Built around Tomidev's `gentle_design` canvas server and `gentle_design_comments` tool (open/list/stop/implement/handoff, stale-source detection, canvas URL) and `/td:design` commands. Without them only "write HTML artboards to design/<slug>/" would remain. Not needed for orchestration; the generic UX guidance it leans on is ported as `gentle-ui-design`.
- **tui-design**: Guidance for Tomidev's own terminal UI; not needed here.
- **ego-browser**: Already installed as a user-level skill on this machine; the docs keep pointing at it.
- **tomidev**: Describes the Tomidev Shell harness and lanes; replaced by the ported ODD core.
